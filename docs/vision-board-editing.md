# 비전 보드 삭제와 워크플로우 편집

## 취소된 프로젝트 정리

비전 보드(`/board`)의 프로젝트 목록에서 상태가 **취소됨**인 카드에만 `삭제`
버튼이 표시된다. 확인 후 해당 프로젝트와 태스크, 연결된 작업, 보드 탭,
`data/artifacts/{project_id}` 산출물이 영구 삭제된다.

취소된 카드가 하나 이상 있으면 목록 머리글의 `취소된 항목 모두 비우기`로 모든
취소 프로젝트를 한 번에 삭제할 수 있다. 삭제 뒤 목록은 즉시 다시 불러오며,
일괄 삭제는 삭제한 개수를 표시한다. 실행 중이거나 완료된 프로젝트는 이 기능으로
삭제되지 않는다.

## 워크플로우 다이어그램 편집

프로젝트 상세 페이지에서 프로젝트 상태가 `plan_ready`(승인 대기) 또는
`paused`(일시정지)일 때 그래프를 편집할 수 있다. 이미 실행된 태스크는 변경할
수 없다.

- 노드를 선택하고 `편집`을 눌러 제목, 설명, 종류, 에이전트, 텍스트 태스크의
  모델, 세부 계획을 바꾼 뒤 `저장`한다. 모델의 `기본값`은 이전에 고른 개별
  모델을 지우고 에이전트 기본 모델을 사용한다.
- 출력 포트에서 대상 노드의 입력 포트로 드래그하면 의존성 화살표가 추가된다.
  터치 환경에서는 노드를 선택한 뒤 `연결`을 누르고 대상 노드를 탭한다.
- 화살표를 선택한 뒤 툴바의 `연결 삭제` 또는 `Delete`/`Backspace`로 삭제한다.
- 자기 참조, 중복 연결, 순환 의존성은 브라우저와 서버에서 모두 거부한다.

저장 또는 연결 변경 뒤 그래프가 다시 렌더링되어 변경된 노드 메타데이터
(`에이전트 · 모델`)와 연결 상태가 반영된다.

## API

모든 수정 API는 `POST`이며, 다이어그램 편집 API는 HTML 보드 조각을 반환한다.
오류는 `400`과 JSON `detail` 메시지로 응답한다.

| 기능 | 경로 | 주요 폼/응답 |
|---|---|---|
| 취소 프로젝트 한 건 삭제 | `/projects/{project_id}/delete-cancelled` | 취소 상태만 허용, 성공 시 `/board` 303 |
| 취소 프로젝트 일괄 삭제 | `/projects/cancelled/clear` | `{"deleted": N}` |
| 태스크 편집 | `/tasks/{task_id}/edit` | `title`, `description`, `task_type`, `agent`, `model`, `extra_instruction`, `o` |
| 의존성 전체 교체 | `/tasks/{task_id}/deps` | 반복 `deps`(선행 태스크 seq), `o` |

`agent`는 활성화된 제공자 또는 `auto`여야 한다. `model`은 선택한 제공자가
지원하는 모델이어야 하며 빈 값은 기본 모델을 뜻한다. `deps`에는 같은 프로젝트의
태스크 순번만 넣을 수 있고, 자기 참조와 순환은 허용되지 않는다.
