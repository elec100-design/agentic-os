# 데스크탑 레이아웃 와이어프레임 — Orca ADE 스타일

Orca ADE(https://www.onorca.dev/) 참고: 좌측 고정 에이전트 채팅 + 실시간 실행 로그,
중앙 메인뷰에 작업물(코드/캔버스) 대신 **작업 진행 과정 자체**를 시각화.
Agentic OS 맥락으로 치환: 중앙 = 비전 보드/프로젝트의 DAG(`project.html` +
`board-editor.js`), 좌측 = 그 프로젝트에 딸린 에이전트 채팅 스레드(`channel.html`
패턴 재사용) + 진행 중인 태스크의 실시간 도구 실행 로그.

## 1. 레이아웃 구조 (데스크탑, ≥1024px)

```
┌───────────────────────────────────────────────────────────────────────────┐
│ topbar: 프로젝트 제목 · 상태뱃지 · [삭제] [⚙]                              │ 48px
├───────────────┬───────────────────────────────────────────┬───────────────┤
│ nav-rail       │  center: vision-canvas (project.html DAG) │ inspector      │
│ 56px           │  flex:1, min-width 0                       │ (선택형, 340px)│
│ (기존 .sidebar │                                             │                │
│  아이콘만 축소) │  - 노드=태스크, 엣지=의존관계 (기존 유지)  │  선택된 노드   │
│                │  - pan/zoom 캔버스 (기존 board-editor.js)  │  = task-detail │
├───────────────┴─────────────────────────────────────────────┴───────────────┤
│                                                                               │
├── chat-rail (좌측 고정, 360px, resizable, collapsible) ──────────────────────┤
│  [탭: 채팅 | 실행 로그]                                                      │
│  ─ 채팅 탭 ─                      ─ 실행 로그 탭 ─                          │
│  기존 channel.html 스레드 목록/   현재 실행 중인 태스크의 stdout/도구        │
│  답장 UI를 프로젝트에 결속        호출을 스트리밍 (job.html의 로그 패널을   │
│                                    사이드바 폭으로 재배치)                    │
└───────────────────────────────────────────────────────────────────────────┘
```

- **좌측 chat-rail** (신규): 폭 360px 고정, 사용자가 드래그로 280–480px 리사이즈,
  헤더의 토글로 접기/펼치기(localStorage 유지, 기존 `nav-toggle` 패턴 재사용).
  내부는 2개 탭:
  - **채팅**: `templates/partials/channels.html` + `channel.html`의 스레드/답장 UI를
    프로젝트 페이지에 이식. 프로젝트당 채널 1개를 암묵적으로 연결(`project.workdir`
    ↔ `channel.workdir` 매칭 또는 `projects.channel_id` FK 신설).
  - **실행 로그**: `job.html`에 있는 실시간 로그 스트림(htmx 폴링 또는 SSE)을
    사이드바 폭에 맞게 재사용. 현재 실행 중인 태스크(`RUNNING` 노드)의 로그를
    자동 추적, 여러 태스크가 동시 실행 중이면 로그 상단에 태스크 선택 드롭다운.
- **중앙 vision-canvas**: 기존 `project.html`의 `#board`(DAG)를 그대로 메인 영역으로
  승격. 현재 폭 제약(`page-wide`)을 제거하고 좌측 chat-rail + 우측 inspector를
  제외한 나머지 전부를 캔버스가 차지하도록 변경.
- **우측 inspector** (선택형, 기존 `#task-detail`을 우측 고정 패널로 전환): 지금은
  모바일 바텀시트/데스크톱 팝오버인 `task-detail`을 데스크톱에서 우측 고정
  340px 패널로 승격(선택 시 슬라이드인, `thread-panel`과 동일한 슬라이드 패턴 재사용).
  아무 노드도 선택 안 하면 패널 자체를 숨겨 캔버스 폭 확보.

## 2. 반응형 규칙

| 브레이크포인트 | nav-rail | chat-rail | canvas | inspector |
|---|---|---|---|---|
| ≥1024px (데스크탑) | 56px 아이콘바 | 360px 고정(리사이즈 가능) | flex:1 | 선택 시 340px 오버레이 |
| 768–1023px (태블릿) | 오프캔버스 햄버거 | 접힘 기본(토글 버튼) | flex:1 | 바텀시트 |
| <768px (모바일) | 오프캔버스 | 하단 탭으로 전환(채팅/로그/보드 3-way 스와이프 또는 탭바) | 풀폭 | 바텀시트 |

기존 `templates/partials/task_detail.html`의 모바일 바텀시트 로직(`task-detail-backdrop`)은
그대로 유지, 데스크톱에서만 우측 고정 패널로 분기.

## 3. 컴포넌트 매핑 (기존 → 신규)

| 신규 UI 요소 | 재사용 소스 | 변경 범위 |
|---|---|---|
| chat-rail 채팅 탭 | `channel.html` 스레드 목록 + `channels.js` | 컨테이너를 사이드바 폭으로 이식, 프로젝트-채널 결속 로직 추가 |
| chat-rail 로그 탭 | `job.html` 로그 스트림 | 폭 축소 대응 CSS, 다중 RUNNING 태스크 선택 드롭다운 신규 |
| 중앙 캔버스 | `project.html` `#board` + `board-editor.js` | 폭 제약 해제(`page-wide` → 풀폭 flex), 좌/우 레일과의 그리드 통합 |
| 우측 inspector | `partials/task_detail.html` | 데스크톱 전용 고정 패널 variant 추가, 기존 팝오버/바텀시트는 태블릿·모바일에 유지 |
| topbar | `project.html` 상단 제목/삭제 버튼 | 높이 고정 48px 바로 승격, 상태뱃지(진행률) 추가 |

## 4. 데이터/상태 흐름 (변경 없음 확인)

- DAG 폴링(`hx-trigger="load, every 2s"`)과 채팅 스레드 폴링(`every 5s`)은 좌/중앙
  패널이 독립적으로 유지 — 서버 API 변경 불요, 레이아웃(CSS grid)만 재구성.
- 실행 로그 스트리밍은 기존 job 단위 폴링을 재사용하되, 어떤 태스크가 "현재
  포커스"인지(사용자가 캔버스에서 클릭한 노드 또는 가장 최근 RUNNING 노드)를
  프론트 상태로 관리해 로그 탭에 바인딩.

## 5. 스코프 밖

- 사이드바 전체 트리 네비게이션(프로젝트 목록)은 기존 `/board` 페이지 역할 유지,
  이번 레이아웃은 프로젝트 상세(`project.html`) 화면에만 적용.
- 캔버스 내 인라인 코드 에디터(Orca ADE의 코드뷰)는 범위 밖 — Agentic OS는
  코드 편집기가 아니라 태스크 오케스트레이션 뷰이므로 DAG 시각화로 대체.
